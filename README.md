# 333 Watcher

一个 Chrome 网页变化监控插件。

## 功能

- 网页变化监控（整页 / 下载链接 / 网页元素）
- 定时检查（chrome.alarms，关机后不错过检查时间）
- Chrome 系统通知
- Chrome 同步（监控配置和通知已读状态随账号同步）
- 立即检查
- 批量设置检查间隔
- 检查结果显示在对应监控项内

## 说明

- 默认检查间隔 500 分钟≈8小时，适合公告类低频监控；如需高频可改为 5-60 分钟。

## 安装

1. 打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录
