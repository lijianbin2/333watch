# 333 Watcher

333 Watcher 是一款隐私优先的 Chrome 网页变化监控扩展。它可以监控整页内容，也可以只监控页面中的某个文字、链接或图片地址；发现变化后，通过 Chrome 通知提醒你。

项目地址：<https://github.com/lijianbin2/333watch>

当前版本：**v0.6.22**

Chrome Web Store 扩展 ID：`gaakbhfclmmeholfdahnpkocdipijndo`

## 为什么使用 333 Watcher

- **监控范围明确**：可以监控整页，也可以只盯一个价格、库存、标题、下载链接或跳转地址。
- **减少误报**：元素和链接变化会进行二次确认，临时页面抖动不会立即触发通知。
- **多设备同步**：监控配置、提醒历史和已读状态可随 Chrome 账号同步。
- **跨设备去重**：在 A 电脑读过同一事件后，其他电脑同步到已读状态时不会再次弹出相同提醒。
- **本地隐私优先**：没有广告、统计、跟踪器或项目自建服务器。

## 功能

| 功能 | 说明 |
| --- | --- |
| 整页监控 | 获取网页 HTML，移除注释、脚本、样式和 `noscript` 后比较内容指纹 |
| 元素文字 | 监控指定 CSS 元素的最深叶子文字 |
| 元素链接 | 监控元素的 `href` 或 `src`，相对地址会转换为绝对地址 |
| 定时检查 | 使用 `chrome.alarms` 调度，支持每 1–10,080 分钟 |
| 立即检查 | 可在扩展面板中手动触发单条监控 |
| 变化提醒 | 显示旧值和新值，并写入可管理的历史记录 |
| 失效与恢复 | 连续失败达到阈值后提醒，监控恢复后再次提醒 |
| 跨设备同步 | 配置、提醒历史和已读状态保存在 `chrome.storage.sync` |
| 配置导入导出 | 通过 JSON 在设备或配置文件之间迁移监控 |
| 内置测试 | 使用虚拟文本和链接验证通知链路，无需访问真实网站 |

## 监控类型

### 整页

适合监控：

- 公告和新闻列表；
- 状态页和版本发布页；
- 商品或活动页面的整体改动；
- 页面中不方便精确定位的区域。

整页模式会忽略 HTML 注释、脚本、样式和 `noscript`，以减少不影响正文展示的改动造成的提醒。动态广告、轮播图或随机页面内容仍可能造成误报；这类页面建议改用元素监控。

### 元素文字

输入 CSS selector，监控目标元素的文字。扩展会优先使用最深的叶子节点，避免外层容器抢占匹配结果。

适合：

- 商品价格和库存状态；
- 公告标题和发布时间；
- 按钮文字、状态标签和计数；
- 页面中唯一且稳定的文本。

### 元素链接

输入 CSS selector，监控元素的 `href` 或 `src`。页面使用相对路径时，扩展会按监控页面的 URL 转换为绝对地址后比较。

适合：

- 下载文件地址；
- 跳转按钮目标；
- 版本安装包或镜像链接；
- 图片资源地址。

## 安装

### 从 Chrome Web Store 安装

1. 在 Chrome Web Store 搜索 **333 Watcher**。
2. 核对扩展 ID：

   `gaakbhfclmmeholfdahnpkocdipijndo`

3. 点击“添加至 Chrome”。

### 从源码加载

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库的 `333-watcher` 目录。
5. 将 333 Watcher 固定到浏览器工具栏。

## 快速开始

### 监控整页

1. 打开需要监控的网页。
2. 点击工具栏中的 333 Watcher。
3. 选择“整页”。
4. 填写名称、URL 和检查间隔。
5. 点击“保存监控”。

新建监控的第一次成功检查只建立基线，不发送提醒。之后检测到内容变化时才会通知。

### 监控指定元素

1. 打开包含目标元素的网页。
2. 在扩展面板中选择“指定内容”。
3. 点击“选择网页元素”。
4. 在页面上点击目标元素。
5. 选择监控文字、`href` 或 `src`。
6. 填写名称和检查间隔后保存。

修改监控的 URL、选择器或属性后，下一次成功检查会重新建立基线。

### 立即检查

在监控列表中点击“检查”，扩展会立即执行一次检查。元素或链接监控还会再次抓取页面确认新值稳定后才发送提醒。

## 管理提醒

扩展面板中的提醒历史支持：

- 查看最近提醒；
- 展开单条历史；
- 标记全部为已读；
- 清除已读历史。

### 跨设备去重规则

每次变化使用稳定事件标识，并带有同步递增的序号。不同状态即使后来再次出现，也会被识别为新的事件；相同事件则不会因为页面从 A 变化到 B、之后又变化回 A 而被错误去重。

当一条提醒已在任意设备标记为已读后，其他设备收到同步状态时会跳过该事件。Chrome 同步并非实时锁：如果两台电脑在同一瞬间同时检查、且提醒尚未被任何设备读到，两台电脑仍可能各发送一次。

已读提醒保留 7 天，之后由扩展自动清理。清除已读历史会删除这些已读事件记录。

## 检查与容错

### 二次确认

元素文字、链接和下载地址变化后，扩展会使用 `cache: no-store` 再抓取一次。只有第二次读取仍得到相同新值时才发送提醒，减少 CDN 缓存、A/B 测试或页面抖动造成的误报。

### 元素选择器自愈

如果原 selector 失效，扩展会在当前页面中按上次文字或地址尝试找回元素，并更新 selector。找不到时不会把一次抓取失败直接当作内容变化。

### 失效提醒

连续检查失败达到 2 次后，监控会标记为失效并发送提醒。后续成功检查会清除错误状态并发送恢复提醒。

### 响应限制

- 单次请求超时：20 秒；
- HTML 响应上限：2.5 MB；
- JSON 响应上限：512 KB；
- DOM 扫描上限：50,000 个节点；
- 文字监控值：最多保存 4,096 个字符；
- 链接监控值：最多保存 2,048 个字符；
- 提醒历史：最多 50 条，并控制在 7 KB 以内。

## 隐私

333 Watcher 不包含广告、统计或第三方分析代码。

扩展会：

- 仅请求用户主动添加的监控 URL；
- 在浏览器扩展环境中保存监控配置和提醒历史；
- 使用 `chrome.storage.sync` 在用户的 Chrome 账号设备间同步这些数据；
- 在用户主动拾取元素时读取当前页面信息。

扩展不会：

- 上传监控配置到本项目服务器；
- 收集浏览历史、账号信息或使用统计；
- 在用户配置之外请求网页；
- 包含广告、跟踪器或分析 SDK。

更多内容见 [PRIVACY.md](./PRIVACY.md)。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存监控配置、提醒历史和已读状态 |
| `notifications` | 发送变化、失效和恢复提醒 |
| `alarms` | 定时执行检查任务 |
| `activeTab` | 在用户主动操作时访问当前页面 |
| `scripting` | 注入元素拾取脚本 |
| `offscreen` | 在受限 DOM 环境中解析监控页面 |
| `<all_urls>` | 访问用户主动添加的 HTTP/HTTPS 监控地址 |

`<all_urls>` 是通用网页监控所需的权限。扩展不会主动扫描或访问未配置页面。

## 故障排查

### 没有收到通知

1. 确认 Chrome 系统通知和网站通知权限未被关闭。
2. 打开扩展面板，点击“检查”手动验证。
3. 检查监控是否已经处于失效状态。
4. 确认目标 URL 无需登录、不会返回 403，或在监控前先登录目标网站。
5. 检查 Chrome 是否开启了省电、冻结或休眠后不运行扩展的限制。

### 元素监控经常失效

- 优先选择稳定、唯一的 selector；
- 避免依赖随机生成的 class 名；
- 动态内容尽量监控稳定的 `data-*` 属性对应元素；
- 目标文字频繁变化时，扩展可能自动更新 selector，但仍应检查网页结构。

### 整页监控误报

整页模式可能受到广告、轮播、时间戳和随机内容影响。优先改用元素文字或元素链接监控。

### 同步没有立即生效

`chrome.storage.sync` 依赖 Chrome 账号和网络状态。离线设备只能在恢复网络后同步；同一瞬间发生的检查仍可能短暂重复。

### 打包

发布包只应包含扩展运行文件，不应包含 `.git`、凭据或测试：

```powershell
$version = "0.6.22"
$zip = "..\333-watcher-$version.zip"
$files = @(
  ".gitignore",
  "add-monitor.css",
  "add-monitor.html",
  "add-monitor.js",
  "background.js",
  "icons",
  "manifest.json",
  "offscreen.html",
  "offscreen.js",
  "picker.js",
  "PRIVACY.md",
  "README.md"
)
Compress-Archive -Path $files -DestinationPath $zip -CompressionLevel Optimal -Force
tar -tf $zip
```
